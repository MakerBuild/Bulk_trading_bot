# Runtime dependencies. Install with install.bat, which handles the two
# quirks below; plain `pip install -r requirements.txt` will not.
#
# 1. bulk-client must come from GitHub, not PyPI. The published wheel omits the
#    trailing signature-domain byte the API requires, so every signature it
#    produces is rejected as "bad signature".
# 2. It must be installed with --no-deps. The package declares bulk-keychain,
#    which it never imports and which has no prebuilt wheel for current
#    Pythons, so pip tries to build it from Rust source and fails.
#
# The commit is pinned: signing is byte-exact against the exchange, and an
# unpinned client that changes the preimage breaks every order silently.
bulk-client @ git+https://github.com/Bulk-trade/bulk-client.git@3a6506e#subdirectory=crates/api-python
