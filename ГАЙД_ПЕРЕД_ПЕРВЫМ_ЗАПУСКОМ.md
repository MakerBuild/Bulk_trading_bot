# Установка с нуля

Для Windows 10 и 11. Если Python и git уже стоят — переходите сразу к шагу 3.

Весь путь занимает 10–15 минут, большая часть — ожидание скачивания.

---

## Шаг 1. Python

Нужен Python 3.10 или новее.

1. Откройте **https://www.python.org/downloads/**
2. Нажмите жёлтую кнопку **Download Python 3.x.x** — сайт сам определит вашу систему
3. Запустите скачанный файл
4. **Внизу окна установщика поставьте галочку «Add python.exe to PATH».** Это самый важный шаг: без неё система не будет знать, где искать Python, и установка бота не начнётся
5. Нажмите **Install Now** и дождитесь конца
6. В конце может появиться кнопка **Disable path length limit** — нажмите её, если есть

**Проверка.** Нажмите `Win + R`, введите `cmd`, Enter. В чёрном окне наберите:

```
python --version
```

Должно ответить `Python 3.13.х` (или другая версия не ниже 3.10). Если пишет «не является внутренней или внешней командой» — галочку «Add to PATH» пропустили. Переустановите Python и поставьте её.

---

## Шаг 2. Git

Нужен, чтобы скачать библиотеку для работы с биржей.

1. Откройте **https://git-scm.com/downloads**
2. Нажмите **Download for Windows** → **64-bit Git for Windows Setup**
3. Запустите файл и всю установку жмите **Next**, ничего не меняя — настройки по умолчанию подходят
4. В конце — **Install**, затем **Finish**

**Проверка.** Откройте **новое** окно `cmd` (старое не подхватит изменения) и наберите:

```
git --version
```

Должно ответить `git version 2.x.x`.

---

## Шаг 3. Установка бота

1. Распакуйте папку с ботом куда угодно — например, на Рабочий стол.
   **Не оставляйте её внутри архива ZIP**, распакуйте по-настоящему: правая кнопка → «Извлечь все».
2. Откройте папку и запустите **`install.bat`** двойным кликом.

Откроется чёрное окно и пойдёт установка. Она:
- создаёт локальное окружение в папке `app\.venv`
- скачивает библиотеку BULK с GitHub
- ставит остальные зависимости
- проверяет, что подпись транзакций работает

Это займёт несколько минут — качается около 200 МБ.

**Посреди установки появится красная надпись `ERROR`:**

```
ERROR: pip's dependency resolver does not currently take into account...
bulk-client 0.1.2 requires bulk-keychain>=0.1.5, which is not installed.
bulk-client 0.1.2 requires solders>=0.26.0, which is not installed.
```

**Это нормально, ничего не сломалось.** Библиотека BULK объявляет две
зависимости, которые сама никогда не использует. Они намеренно не ставятся:
одна из них не собирается на современных версиях Python и уронила бы установку.
Установщик предупреждает об этом строкой выше.

Смотреть надо не на эту надпись, а на последние строки:

```
  Signing check: OK

  Done. Next:
    1. Put your base58 private key on one line in private_key.local
    2. Edit settings.yaml
    3. Run run.bat
```

Если окно закрылось мгновенно и вы ничего не успели прочитать — запустите `install.bat` ещё раз, оно теперь дождётся нажатия клавиши.

---

## Шаг 4. Ключ

1. `install.bat` уже создал файл **`private_key.local`** в папке с ботом
2. Откройте его Блокнотом и вставьте приватный ключ вашего master-аккаунта BULK **последней строкой**, одной строкой, без кавычек
3. Сохраните (`Ctrl + S`) и закройте

Ключ никуда не отправляется — он читается только на вашем компьютере.

**Сразу после первого запуска зашифруйте его:** в меню выберите `4. Accounts Management` → `Encrypt Private Key`. После этого в файле будет зашифрованный контейнер, а бот будет спрашивать пароль при старте.

Ключ нужен только от master-аккаунта. У саб-аккаунта своего ключа нет — он создаётся и подписывается мастером, и бот находит его сам.

---

## Шаг 5. Деньги на аккаунте

Бот не может создать аккаунт на бирже за вас.

1. Зайдите на **https://bulk.trade** тем же кошельком, от которого дали ключ
2. Внесите USDC — этим создаётся торговый аккаунт
3. Запустите бота (`run.bat`) и выберите `4. Accounts Management` → `Create New Subaccount`
4. Там же — `Balance Subaccounts`, чтобы перекинуть часть маржи на саб-аккаунт

Без саб-аккаунта стратегия не запустится: ей нужны два счёта, чтобы держать противоположные позиции.

**Сколько нужно денег.** Маржа считается так: `(нога₁ + нога₂) / плечо`. При
двух ногах по $100 и плече 10 это $20 — и столько должно быть **на каждом из
двух счетов**, а не суммарно. Плюс запас: если во время входа цена уйдёт,
хеджу может не хватить, и бот остановится. Держите хотя бы вдвое больше
расчётного.

Отдельно про минимальный размер: биржа не принимает ордер дешевле своего порога
— $1 у BTC-USD, $50 у ETH-USD и SOL-USD. Поэтому нога меньше $50 в ETH просто
не откроется, сколько бы денег ни лежало на счёте.

## Шаг 6. Настройки

Откройте **`settings.yaml`** Блокнотом. Всё, что обычно меняют, — в верхней половине:

| Строка | Что означает |
|---|---|
| `symbol:` | какая пара торгуется |
| `notional_usd:` | на какую сумму в долларах набирать за цикл |
| `leverage:` | плечо |
| `hold_minutes:` | сколько минут держать позицию открытой (можно диапазон, `0.5-1`) |
| `burn_usd:` | на какой сумме комиссий остановиться |
| `max_phase_minutes:` | через сколько минут считать вход или выход зависшим |

Размер задаётся **в долларах**, а не в монете: `notional_usd: 100` — это $100
и в BTC, и в ETH. Бот сам пересчитает в количество по текущей цене при запуске.
Поэтому пару можно поменять, не пересчитывая цифру.

Старый вариант `size:` (количество монеты) тоже работает, но он привязан к цене
одной монеты: `size: 2.0` — это $200 в SOL и $5,200 в ETH. В одной ноге должно
стоять либо `notional_usd:`, либо `size:`, но не оба сразу.

Начните с малых размеров. Биржа не примет ордер меньше $1 по BTC и меньше $50 по ETH.

## Шаг 7. Запуск

Запустите **`run.bat`**. Откроется меню:

```
1. Start                  начать торговлю
2. Active Strategy        что открыто сейчас
3. History                прошлые сделки
4. Accounts Management    саб-аккаунты, балансы, ключ, удаление данных
5. Configuration          цели и прогресс
6. Close All Positions    отменить всё и закрыть позиции
```

Перед первой торговлей проверьте настройку — закройте меню (`0`) и в том же окне `cmd` наберите:

```
run.bat check
```

Это ничего не торгует, только проверяет, что ключ читается, аккаунт найден и саб-аккаунт на месте.

## Шаг 8. Как останавливать

Это самое важное место в гайде, прочитайте до запуска.

**Ctrl+C и крестик окна НЕ закрывают позиции.** Они только отключают бота. Ваши
лимитные ордера остаются жить на бирже и могут исполниться — а хеджировать их
уже некому. Из дельта-нейтральной пары получается односторонняя позиция без
присмотра. Прервать бота в середине входа — худшее, что можно сделать.

**Правильно так:**

1. Откройте **второе** окно в папке бота и выполните:

   ```
   run.bat flatten --live
   ```

   Она снимает все ордера, закрывает обе позиции по рынку (только на
   уменьшение — открыть новую она не может физически) и сбрасывает состояние.
   Спросит подтверждение.

2. **Дождитесь, пока команда отработает.** Только после этого Ctrl+C в первом
   окне.

То же самое делает пункт `6. Close All Positions` → `2. live`, если бот стоит
в меню и ничего не делает.

Если `flatten` почему-то не отрабатывает — зайдите на bulk.trade и закройте
позиции руками на обоих счетах, мастере и саб-аккаунте. Ордера тоже снимите
на обоих.

## Шаг 9. Если бот сам остановился

У бота есть предохранители: слишком большая односторонняя экспозиция, слишком
крупная позиция, несколько отказов биржи подряд, пропавшие котировки, а также
вход или выход, который не завершился за `max_phase_minutes` — это ловит
случай, когда лимитный ордер просто некому исполнить. Любой из
них останавливает торговлю, закрывает позиции и записывает причину.

При следующем запуске вы увидите:

```
state file records a halt: reject_streak: sub1 has 5 consecutive rejected
transactions -- last was REJECTED_INVALID: ...
```

**Сначала прочитайте причину** — она там написана целиком, вместе с ответом
биржи. Это и есть смысл остановки: понять, что случилось, прежде чем
продолжать.

Затем снимите остановку:

```
run.bat flatten --live
```

Она же и закроет позиции, если что-то осталось открытым. Файл состояния
удалять руками не нужно.

## Если не запускается

**«python не является внутренней или внешней командой»**
Python поставлен без галочки «Add to PATH». Переустановите с ней.

**«Not installed yet. Run install.bat first»**
Не выполнен шаг 3, либо `install.bat` запускали не из папки бота.

**Установка падает на библиотеке BULK**
Нет git или он поставлен уже после открытия окна `cmd`. Поставьте git, закройте все чёрные окна, запустите `install.bat` заново.

**«no BULK account exists»**
На кошельке ещё нет аккаунта BULK. Внесите USDC на bulk.trade (шаг 5).

**«master has no sub-account»**
Не создан саб-аккаунт: `4. Accounts Management` → `Create New Subaccount`.

**Окно мигает и закрывается**
Запустите файл из `cmd`, чтобы увидеть сообщение: откройте папку, наберите `cmd` в адресной строке проводника, Enter, затем `run.bat`.

**«access denied»**
Эта сборка работает только для аккаунтов, зарегистрированных по реферальной
ссылке или инвайт-коду её владельца. Проверяется master-аккаунт, а не
саб-аккаунт. Если вы уверены, что заходили по ссылке — проверьте, что ключ в
`private_key.local` именно от того кошелька: адрес печатается в первой строке
лога при запуске.

**«the affordable size ... is under the $50 minimum the market accepts»**
Нога меньше минимального ордера этого рынка. Если в сообщении сказано
`Nothing was scaled down` — денег хватает, дело в самой цифре: поднимите
`notional_usd` до минимума рынка или выберите пару с порогом пониже. Если же
сказано `Fund the accounts` — тогда действительно не хватает маржи.

**«hold_minutes range runs backwards»**
В диапазоне меньшее число пишется первым: `0.5-1`, не `1-0.5`.

**Тесты пишут «No module named pytest»**
Так и задумано: инструменты разработчика не ставятся, запускающему бота они не
нужны. Команда для установки печатается тут же.

`app\state` — то, что бот держит открытым (**не удалять во время работы**).

## Как стереть свои данные с компьютера

`4. Accounts Management` → `4. Erase Local Data`. Показывает, что именно лежит
и сколько занимает, и даёт удалить по отдельности:

| | |
|---|---|
| Trading state | что бот держит открытым, и записанные остановки |
| Private key | **стирает ключ, сам файл остаётся** — с инструкцией, куда вставить новый |
| Build caches | служебные кэши; в них попадает имя вашего пользователя Windows |

Ничего из этого не касается вашего аккаунта на бирже, позиций и денег —
удаляется только то, что хранится на компьютере.

На удаление ключа обычного `yes` недостаточно: нужно набрать `DELETE KEY`.
Если у вас нет второй копии ключа, вы потеряете доступ к аккаунту навсегда и
из любых программ, не только отсюда. Сначала убедитесь, что ключ записан
где-то ещё.
